# Set up Albo

1. Connect the bundled `albo` MCP server at `https://mcp.albo.inc/mcp`.
2. Complete the Albo OAuth sign-in in the browser. Never ask the user to paste access or refresh tokens into chat.
3. Verify the connection by listing tools. A successful connection includes `findCollections`, `findExtracts`, `saveImport`, and `searchPlacesNearby`.
4. If authentication fails, disconnect and reconnect once. If it still fails, direct the user to `support@albo.inc` and include the client surface they used, without including credentials.
